
# NumPy - Aggregate Functions

## Overview
Learning NumPy aggregate functions to summarize
and analyze numerical datasets.

## Functions Covered

| Function | Purpose |
|---|---|
| np.sum() | Calculates total |
| np.mean() | Calculates average |
| np.std() | Calculates standard deviation |
| np.var() | Calculates variance |
| np.min() | Finds minimum |
| np.max() | Finds maximum |
| np.argmin() | Index of minimum |
| np.argmax() | Index of maximum |
| np.median() | Calculates median |
| np.percentile() | Calculates percentile |
| np.cumsum() | Calculates cumulative sum |
| np.unique() | Finds unique values |

## Axis Parameter

- axis=0: Performs operation column-wise
- axis=1: Performs operation row-wise
